1. Windows深层测试目录触发 `WinError 3`：受控探测235字符路径写入成功，275字符失败。改用较短克隆路径后53项全过。没有修改系统长路径设置，没有宣称修复任意长路径兼容。换机建议使用 `C:\Novel\` 等短目录。
2. 旧本地仓库所有者与当前执行账号不同，Git拒绝访问。验证命令仅针对确切目录使用临时 `safe.directory`，未扩大系统或全局信任范围。网络Git命令临时指定OpenSSL，保留TLS验证。
