# Safety and quality gates

## Provenance gate

- Every source-specific claim has a source ID and locator.
- Cross-book synthesis distinguishes observation from new inference.
- Missing evidence is marked unknown; it is not filled from model memory.

## Identity gate

- Books remain separate unless explicitly declared volumes of one canon.
- Same names do not prove same entities.
- Contradictions are retained and explained rather than silently reconciled.

## Originality gate

- No long excerpts, reconstructed chapters, quote banks, or searchable substitute for the original.
- No downstream prompt asks for exact imitation of a living author.
- Names, signature characters, proprietary settings, distinctive scenes, and recognizably copied phrasing are excluded from generated drafts.
- Style becomes neutral craft variables and may be combined with the user's own preferences.

## Use gate

- Keep skills distilled from copyrighted novels private unless licensing permits sharing.
- Treat the converter's code license separately from source-book copyright.
- If the user requests close reproduction, redirect toward high-level traits and original alternatives.

## Consistency gate

- Timeline facts include when they are true.
- Character knowledge is tracked separately from reader knowledge.
- World rules record cost, boundary, exception, and enforcement.
- Every setup/payoff pair records status: open, partially paid, paid, or abandoned.

## Final checks

Search generated files for large verbatim passages, unattributed findings, source-ID collisions, broken links, missing selected dimensions, and user canon contaminated by reference canon. Report unresolved warnings.
